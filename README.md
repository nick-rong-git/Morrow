# Morrow - 极简终端背单词系统

> Build your vocabulary for tomorrow, effortlessly in your terminal.

Morrow 是一款专为极客与开发者打造的高质感终端（CUI）背单词工具，深度集成墨墨记忆规划算法与微软 Azure 神经拟真音频引擎。

---

## 🌟 核心特性

- **全新模块化架构**：核心拆分为 `client`、`audio`、`dict`、`config` 与 `ui` 独立组件。
- **双模终端视觉（CUI）**：
  - **全功能卡片模式**：高信息密度单词卡片、分词性释义药丸、真题例句高亮、助记联想。
  - **摸鱼代码伪装模式**：实时仿真 IDE 编译输出与微服务日志，不经意间攻克词汇。
- **录音室级神经发音**：
  - **单词原声**：直连墨墨官方真人原声 CDN。
  - **例句朗读**：全面升级为微软 Azure 神经拟真人声（Jenny / Sonia），具备自然语调、弱读与换气停顿。
  - **静默后台预取**：看词回忆时自动预合成例句 MP3，按键发音 0 延时即按即播。
- **全功能操作链**：
  - `[0]` 斩词 / 熟知（WELL_FAMILIAR，永久移出学习队列）
  - `[u]` 防手抖误触撤回（回退到上一个单词）
  - `[/]` 终端即时查词典（英汉 + 英英双解）
  - `[r]` 提前复习（主动从词本抽取批次强化加词）
  - `[b]` 老板键一键应急监控屏
  - `[p] / [e]` 单词与例句独立发音，`[t]` 随时切换美音/英音

## 🚀 启动方式

- **Windows 用户**：双击根目录下的 `start_morrow.bat` 即可启动。
- **命令行方式**：
  ```bash
  python morrow.py
  ```
