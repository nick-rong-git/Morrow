# Morrow · 终端背单词

Morrow 是一个连接墨墨背单词 Web 学习端的终端客户端。你可以在终端回忆单词、查看释义和例句、提交判答，沿用墨墨账号的学习计划。

## 快速开始

需要 **Python 3.10 或更新版本**。背词需要联网和墨墨账号。音频播放与剪贴板导入使用 Windows 接口，自动获取背词凭证需要已安装的 Edge 或 Chrome。

首次使用时，在项目目录打开 PowerShell，创建虚拟环境并安装依赖。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start_morrow.bat
```

以后双击 `start_morrow.bat` 即可。也可以用安装过依赖的解释器运行 `python morrow.py`。首次启动时按向导完成[凭证配置](#配置墨墨凭证)，然后在首页按 `y` 开始背词。

## 配置墨墨凭证

### 背词凭证 `ws_token`

取词、提交判答、撤回和提前复习都需要这个凭证。首次启动会打开配置向导。更新时从首页按 `s` → `1` 进入向导。

1. 选择网页登录，Morrow 会打开独立的 Edge 或 Chrome 窗口。
2. 在墨墨官网登录并进入学习页。
3. Morrow 识别到学习连接后关闭临时窗口，并验证、保存背词凭证。

手动配置时，从首页按 `s` → `7`，或者在向导里选择“手动粘贴”。登录[墨墨 Web 学习页](https://www.maimemo.com/home/web_study)，在开发者工具的 **网络 → WS** 中找到 `webstudy` 请求，复制完整的 WebSocket 地址即可。也可以直接粘贴其中的 `token` 值。

### 开放 API 凭证 `rest_token`（可选）

此凭证用于在首页显示墨墨的今日学习进度。只用 Morrow 背词时，配置 `ws_token` 就够了。

- **网页领取**。首页按 `s` → `2` 打开[墨墨官方凭证页](https://open.maimemo.com/open/api/v1/tokens/openapi)。登录并复制 Token，再回到 Windows 终端按回车导入。
- **App 领取**。在墨墨背单词中打开 **我的 → 更多设置 → 实验功能 → 开放 API**。复制 Token 后，在 Morrow 首页按 `s` → `2` → `m` 手动粘贴。

Morrow 会验证凭证后再保存。凭证和偏好保存在项目根目录的 `config.json`，该文件已加入 Git 忽略规则。分享配置时可使用 `config.example.json`。

## 背词流程

1. 看词时先回忆读音和释义。默认在此阶段保持安静。
2. 按 **空格或回车**显示答案，默认会读出单词。翻开答案后，可以继续按空格或回车重播。
3. 按 `1`、`2`、`3` 或 `0` 提交认识程度。需要纠正上一题时，按 `u` 或退格。

按 `m` 切换显示模式。**卡片模式**显示独立词性、释义、例句和助记。**伪装模式**使用单色 JSON，词性与释义逐行显示。两种模式都最多显示三条例句，对应 `4`、`5`、`6`。

### 发音设置

首页按 **`s` → `5`** 可以选择单词自动发音的时机。

| 选项 | 行为 |
| --- | --- |
| 翻面时（默认） | 显示释义后发音 |
| 看词时 | 显示新单词时发音 |
| 关闭 | 用 `p` 手动播放，翻面后也可按回车或空格重播 |

按 `s` → `4` 设置默认美音或英音，按 `s` → `6` 控制是否自动朗读第一条例句。翻面时两种自动朗读都开启的话，会先读单词，再读例句。

## 常见问题

- **启动提示缺少依赖**。用上面的 `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` 安装到启动脚本使用的虚拟环境。
- **网页登录后一直在等待**。在浏览器里进入实际的墨墨学习界面，让网页建立学习连接。也可以用设置里的 `7` 手动粘贴完整连接地址。
- **首页提示开放 API 凭证失效**。按 `s` → `2` 验证并保存新的 `rest_token`。背词凭证从设置里的 `1` 或 `7` 更新。
- **翻面后没有声音**。先按 `p` 测试单词发音，再检查 Windows 音频输出和 `s` → `5` 中的自动发音设置。单词发音和例句在看词时后台预取，音频缓存默认放在 `data/audio_cache/`。

CLI 学习流程位于 `morrow/cli.py`，墨墨连接位于 `morrow/client.py`，终端界面位于 `morrow/ui/`，音频播放与缓存位于 `morrow/audio.py`。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
